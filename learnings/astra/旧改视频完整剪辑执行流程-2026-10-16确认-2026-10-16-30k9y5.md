# 旧改视频剪辑执行流程

生效日期：2026-10-16。适用于后续基于真实素材的旧改视频制作和返修。依据用户本次确认的工作流及优化意见执行；账号、城市、品牌、人物、材料、交付审批和素材范围以当前任务最新要求为准。账号批次的明确局部例外只适用于该范围，不扩展为通用许可。

## 一 执行顺序与审核原则

任务核对与历史查重 → 筛选文案及预查关键素材 → 修改文案并归档 → 本地CosyVoice3配音与听审 → 语义选镜与动作编排 → 粗剪审核 → 字幕与混音 → 成片终审及文件检查 → 按任务审批交付并更新使用记录。

各阶段分别记录待审、通过、待修和具体问题。审核证据绑定当前文本、声音、素材区间和成片版本；旧版通过不代表新版通过。必要审核未完成或未通过时只留项目内，不投递发布共享目录。机器检查辅助定位问题，不替代实际视听审核。

## 二 开工核对

1. 核对账号、实际发布日期、目标城市、空间主题、文案来源、素材范围、获准人物及材料、品牌样式、音色、输出位置与最终放行人。
2. 读取本流程、当前账号任务交接、相关品牌配置，以及近期有效成片和本批使用记录。查重范围注明实际覆盖的日期、账号和版本；记录缺失时先补核，不能直接宣称无重复。
3. 按需读取剪辑学习知识：按表达目的选择信息职责选镜、动作匹配、声画错位、空间连续、时间省略等适配方法，教程方法尚未经当前素材试剪时视为候选，选择适配方法。新方法先试剪，用实际效果判断是否保留。

通过条件：范围、输入、审批要求和查重对象明确；影响制作的关键缺口已解决。

## 三 文案筛选 修改与归档

1. 优先现有文案库，按城市、空间、材料、主题、现有素材与近期使用情况筛选后再随机选稿，不在全库盲抽。分别核对同日各账号、同批及近期稿件，去城市、人名和标点后比较正文，并实际检查开头、主题、结构、结尾是否雷同。
2. 以“开场约3秒建立钩子 → 痛点 → 施工说明或有依据的前后对比 → 主题相关引导”作为检查框架，不机械固定每段时长或强制所有视频同一结构。钩子可采用问题、结果、细节或误区，避免夸大承诺。
3. 配音定稿前预查开场、关键操作和对比画面，确认有能支撑表达的候选。前后对比核对门窗、布局等同空间依据；缺少证据时换稿、换表达或换镜，不拼接出虚假同户案例。
4. 自主修正城市、错别字、流畅性和结构缺口；补写须符合事实和服务范围，不捏造价格、工期、客户关系或材料性能。结尾设置具体、与主题有关的行动引导，每条只采用一个转化路径，避免多重要求及同批机械复用。
5. 将改稿作为文案文档中的独立版本保存，保留准确来源文件、段落、原稿、使用全文、差异、适用账号/城市/日期和版本。沿用当前任务指定文案文档；未指定写回位置时先在项目文案记录保存，不覆盖来源原稿。

通过条件：全文通读流畅、事实适用、关键画面可取得、同日及近期模板查重完成、引导完整且版本可追溯。文案与全流程审核均记录当前版本的实际证据；自主选稿改稿授权不等于免除事实、适用范围、声音、素材及终审检查。

## 四 本地声音克隆配音

1. 使用本机CosyVoice3及当前获准的声音克隆参考，按所属账号最新配置执行。优先整段自然合成；保留原速音频和处理记录，已约定的语速处理只执行一次，不反复累计提速。
2. 配音文本保留必要标点，检查地名、多音字、数字、单位和专业词读法。ASR全文核字作为辅助，逐条实际听审最终处理后的完整音轨。
3. 检查错读、漏字、多字、重复、词中断句、异常停顿、声音变形、音色漂移、截头、吞尾及流畅度。发现问题先定位文本、断句或合成问题，修复后复听；分段修复时检查音色和语气接缝。
4. 口播文字变化后同步更新声音、字幕及对齐，不用仅改字幕掩盖旧读音。按最终音轨建立语句时长和自然气口标记。

通过条件：当前完整音轨听审通过，文本核对完成，最终时长和版本明确。无法实际听审时登记待审，不以ASR替代。

## 五 语义选镜与三层查重

先明确每个语义段需要表达的信息，再检索候选；文件名与标签只作线索，实际查看拟用区间及转场余量，核对人物、空间、施工阶段、材料、动作与结果。

选镜记录至少包含：语义段、表达目的、准确源/稳定身份、源哈希或身份依据、源入出点、房间/场景、动作阶段、拟用时长、变速、前后关系、主备镜、重复检查及审核结果。文件哈希不同不代表画面不同。

|查重层级|必须检查|处理要求|
|---|---|---|
|单条视频内部|相同片段、同源相邻或重叠区间、相似动作与构图反复出现|避免重复填充，优先换适配镜头；有叙事必要的回看明确记录用途|
|同批视频之间|准确源、区间、同房间、动作、构图及封面用帧|按账号批次最新要求检查，避免批量复用小素材池|
|近期有效成片|含独立新增和返修后的有效版本，比较源与视觉场景|优先未用准确源，其次少用且适配的候选；记录比较范围|

同源换区间、裁切、镜像、变速或改名仍纳入重复检查，不能据此当作新镜头。不同源也可能是同一拍摄内容或相似构图。局部任务明确允许跨账号同源非重叠区间时，仍须检查单条内部重复及该任务的空间/构图限制。

逐镜排除模糊、严重抖动、过曝丢细节、拉伸失真、黑边、水印、叠字、禁用人物/材料和语义不符镜头。素材库已审核不等于当前选段语义审核通过。痛点描述不能误配明显完工效果；功能或结果断言须有对应依据。

通过条件：每个语义段有适配且实查的镜头，三层查重完成；问题重复已换镜或符合明确例外并登记，材料/人物/空间关系成立。

## 六 动作与时长编排

1. 一句话、一个镜头、一页字幕不强制对应。镜头可跨多句口播；一句话也可用多个互相支持的镜头。配音时长是约束之一，不能据此机械截断动作。
2. 保留观众看懂所需的动作起因、关键接触、推进和收势，不要求展示全部重复劳动。先找合适长度的完整动作，再考虑跨句延续或省略重复，最后才考虑局部加速。
3. 加速优先放在无新增信息的重复段，关键操作、结果观察和人物说话留足理解时间。检查速度衔接、工具接触和手部运动，失真或显得不真实时换段或重排，不用极端加速硬凑时长。
4. 连续动作换角度时检查人物、工具、接触状态、动作阶段与运动方向；过程省略保留必要信息与真实顺序。逐镜记录“新增什么信息”，逐次省略记录“省掉什么、是否改变理解”。短片时长及加速不作为真实工期证据。
5. 开门、挥手等动作可在遮挡、运动衔接或动作完成处切换，不强制等动作结束后叠动画。先试自然直切；需要表达空间或时间变化时再选转场，检查重影、方向、亮度和真实运动余量，不冻结尾帧凑长度。
6. 气口、切点和字幕边界分别安排。镜头尽量在实际自然气口后约0.6秒切换；若损害动作完整、语义或连续性，采用合理切点并记录原因，不人为制造停顿。

粗剪通过条件：正常速度连贯观看，声音与镜头语义一致，动作与时间关系清楚，无重复填充、无关画面或错误案例因果；切点与变速实际看过。

## 七 字幕 配乐与画面优化

1. 字幕依据最终音轨对齐，按完整语义分页，不拆词、不因换页打断口播。显示字幕无标点，配音文本保留必要标点。
2. 字幕置于画面下部三分之一区域并居中，避开底部平台文案、右侧按钮、手部工具及关键信息。沿用当前品牌预设，并按最终竖屏显示实际检查字号、安全边距和遮挡。
3. 全部字幕加适度描边。关键词按语义突出，可同页多处；以黄色为主，红色用于警示/否定等明确用途，适度放大，检查断行和布局跳动，不整句无差别强调。
4. BGM对照近期和同批曲目轮换，按叙事选曲，沿用确认响度，不累计历史增益；音乐和音效不能盖住口播。变速素材的原声按听感保留、调整或静音，避免异常噪声。
5. 统一相邻镜头亮度、色彩和方向，保留真实细节，不用过度调色补救不可用源。结尾声音、字幕及引导贴纸一致，片尾自然收束，无无意的无口播空段。

通过条件：最终尺寸字幕清楚且不遮挡，文声字一致；完整终混听审通过，人声清晰，配乐轮换已查，画面连续自然。

## 八 终审 文件验证与交付

1. 对当前导出版本完整、正常速度、连贯视听审核。核对开场、语义配镜、动作、变速、转场、字幕、声音、结尾与整体节奏，不以截图、联系图或旧版审查代替。
2. 再核对单条、同批、近期视觉重复及当前实际使用区间；检查无错人物、错材料、错空间、错误前后对比和未经证实的承诺。
3. 运行现有机器QA、完整解码及输出规格检查，核对时长、分辨率、帧率、画幅、音轨和文件完整性。复制交付后核对源与目标SHA一致。
4. 只有全部必要审核通过且满足所属任务放行要求后才复制共享。需指定人员批准的账号继续等其批准，通用流程不取消该门槛。共享内文件种类、命名及清理仍按该任务授权执行。
5. 更新有效版本、文案来源与差异、音轨身份、准确素材源及区间、场景/构图、变速、封面用帧、BGM、查重范围、审核证据与交付路径。返修旧版保留但不重复计为有效新片。

## 九 返工定位与复核范围

|发现问题|返回环节|必须同步复核|
|---|---|---|
|文案事实、结构、城市或引导错误|文案|声音、字幕、选镜及时间线；改口播后重新听审|
|错读、卡顿、音色或语速问题|配音|最终音轨、字幕对齐、气口与镜头时长、混音|
|语义不符、重复、禁用源、错误空间关系|选镜|新选段、查重、动作衔接、字幕遮挡及前后镜关系|
|动作截断、加速失真、转场突兀|动作编排与粗剪|源区间及余量、后续时间线、字幕和声音同步|
|仅字幕样式、分页或重点问题|字幕|文字及定位、完整字形、最终画面；涉及口播文字则返回配音|
|音乐盖人声、爆音或结尾空段|混音或时间线|完整终混、片尾和受影响画面|

修复后先检查受影响环节，再对新的当前成片完成整片终审和必要文件验证，更新证据。审核记录写明版本、问题位置、修复办法、实际复核方式和结果；未完成的项目明确待审，不自动勾选通过。

## 十 每条视频的交付前检查单

- [ ] 任务范围、品牌及所属账号放行要求明确
- [ ] 文案来源、原稿、改稿与差异已保存，事实及引导审核通过
- [ ] 同日/同批/近期文案模板查重完成
- [ ] 当前最终音轨全文听审通过，ASR辅助核字完成
- [ ] 关键镜头实际查看，语义、人物、材料、空间及动作成立
- [ ] 单条内部、同批、近期三层视觉查重完成，例外有明确依据
- [ ] 动作、变速、时间省略与转场连贯，镜头/字幕/气口独立安排
- [ ] 字幕无标点、描边及重点正确，最终画面安全区检查完成
- [ ] BGM轮换与完整终混审核通过
- [ ] 当前成片完整连贯视听终审、机器QA及全解码通过
- [ ] 所属任务审批通过，交付复制SHA一致，使用记录已更新
