# ASTRA 项目说明

ASTRA 用真实拍摄素材制作和返修中文旧房翻新短视频。团队共享的是制作方法与审核标准；视频原片、成片、客户资料、账号信息、机器配置和运行记录由各自的项目存储管理。

## 一条视频的工作流程

1. 确认本条任务的地区、文案来源、素材范围、人物与材料使用范围及交付要求。
2. 核对原稿并记录实际使用文字；按语义规划镜头、字幕和配音。
3. 查看候选素材的实际画面，核对来源与可用区间，再比较近期成片中的重复场景。
4. 制作预览，检查画面、声音、字幕、配乐和节奏；针对问题返修。
5. 对最终版本完成画面复核、口播与字幕核对、文件完整性检查，并保存可追溯的交付记录。

项目规则见 `rules/astra/video-production.md`。这份首批共享内容提供协作基线，不包含自动制片程序、素材或客户数据；执行具体任务仍需读取该任务当前获准的本地配置与来源。
