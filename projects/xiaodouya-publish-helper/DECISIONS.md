# 有效决策

## 2026-10-12：保留基线，仅修改已验证的兼容性条件

由于原源码缺失，本轮采用可重复构建的编译常量替换，严格限定模块、函数和匹配次数，并验证其余模块保持原样。这是临时恢复措施，不是长期源码架构。
不重写整个项目：没有原测试和完整业务资料，重写容易破坏已有保护；不盲目重装小豆芽：尚无证据证明安装损坏。
后续继续开发前应优先找回原源码或逐模块恢复源码与回归用例。
本轮候选修复只允许同源 blob 预览；仍须先通过原有账号、文件指纹和唯一预览检查。预览可播放不等于平台上传完成或发布成功。

## 2026-10-12：r2 恢复连接调用源函数，修复误分类并保存诊断

反汇编证实原 `_call` 将接收或 JSON 解析的所有异常标为超时；模拟断线已复现。用可维护源函数替换这一个方法，保留单次发送、按指令 ID 匹配和有界等待，不增加自动重传。异常连接停止继续发送，防止在结果未知时沿用旧连接。
自动诊断仅记版本、系统种类/版本/架构、阶段、白名单方法、原因和耗时，不记参数、异常原文、账号、正文、URL、主机名或凭据。诊断写入失败不掩盖原错误。
本轮不凭空延长超时、不改账号选择规则。现场账号读取失败仍需诊断，不把错误分类修复等同于连接问题已解决。

## 2026-10-12：实际抖音输入、排期和页面就绪
采用浏览器原生输入并确认内嵌页面焦点；不使用坐标、开发机路径或修改 React 私有模型。普通 #文字不视为话题选中，逐个等待标签实际稳定。时间选择保留平台自身控件，删除竞争滚动，最终精确读回。
按用户明确流程允许直接所属交付文件夹提供日期，时分沿用助手设置；多日期或冲突仍留空，不猜排期。
进入上传页后须等待文件控件就绪再开始；已有未发布记录仍阻止上传，提示明确原因，不自动丢弃。当前记录仅因本次用户明确授权才清理。
保留导入后人工核对与显式上传动作；上传流程负责导航，无需运营提前打开空白页。跨电脑适配继续使用语义元素、账号与实际状态，不固定屏幕坐标或延迟睡眠代替就绪判断。

## 2026-10-12：取消文案硬截20字
用户确认珠海首句应截止“不拆不砸”，不带下一句“真正做到”。修复统一生成入口，按明确句末或保守重复谓语起句裁边界，而非单独替换客户文案。超过长度交人工精简，未知句意不擅自补写；不新增模型服务或外部传输。原有人工文案保持，重置由用户显式触发。局部规则不能保证所有无标点字幕都有正确语义边界，保留人工核对。

## 2026-10-12：无标点受众招呼句作为首句
依据用户莆田截图与明确期望，开头“……朋友注意了”本身是完整首句，后续自我介绍和施工说明不属于作品描述。本地边界识别增加有起点限制的招呼句模式，保留疑问/转述反例测试，不按特定城市或固定字数剪裁。不把有限规则包装为通用语义识别。

## 2026-10-12：以用户指定的短视频区间取字幕，不继续叠加客户文案规则
泉州原视频实测确认前2秒两段字幕可以组成目标首句；原默认12秒导致混入讲解。默认改2秒，密集取帧复用原有相邻帧共识去重，禁止自动扩展；人工句尾时间继续有效。真实莆田首句要3秒，因此明确保留人工指定终点，不宣称2秒等价于完整首句。旧缓存须重新识别，不能靠重置文案按钮修复。

## 2026-10-13：识别结果与完整句判断分开
运营三条同源视频记录证明，固定2秒候选被智能断句need_more判为整个预处理失败。need_more只说明范围不足，不说明OCR失败；保留原识别文字进入待核对，原人工确认门禁不变。uncertain/改写/真实识别异常不降级放行。真实OCR加注入need_more的复验与运营实际模型调用分别报告。

## 2026-10-13：完整扫描与复核分开预算，失败留取证信息
原账号读取两轮共享60秒，使用原扫描器和模拟慢响应复现首轮约55秒后第二轮超时。给每轮独立预算，最多三轮、连续两轮完整结果一致才返回；避免一味延长所有连接超时或跳过复核。一次扫描超时/断线不自动重启，保持结果未知不重试；重名直接拒绝。
不据每日发布一百多条推算账号数，不凭旧metadata_input诊断认定账号超时根因。保留扫描器和账号切换函数，减少无证据更改；新增阶段与轮次计数诊断，便于现场不能立即取证时先交付有界验证包。大列表组件测试是合成DOM，不等于运营兼容验收。若后续证实单轮本身超过60秒或虚拟列表不兼容，再据诊断处理，不取消稳定性或账号唯一性检查。

## 2026-10-13：加载中的扫描不能作为已完成一轮
运营r11日志18/20/23且总共6.8秒，否定该次故障是预算不足。真实浏览器合成分批加载页面复现同样三轮结果；旧版忽略加载标记/待展开节点，并在初始化时忽略尚未溢出的滚动容器。r12修正单轮扫描的就绪与滚动判断，不用无限增加扫描轮次、不接受最后一轮部分结果、不绕过两轮一致性。
使用DOM变化、可见加载状态、已点击节点展开状态和有限稳定窗口组合判断；保留全轮截止时间，所有退出清理观察器。稳定窗口不能证明无信号的任意网络延迟已结束，因此不宣称全配置兼容。保留精确身份与上传门禁；诊断记录计数而不是业务内容，现场若仍失败可定位等待或滚动阶段。
